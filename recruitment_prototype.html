Cơ Chế Inbound Webhook Tự Động Tiếp Nhận Bài Thi Qua Email

Khi ứng viên nhận email đề thi từ hệ thống ATS, nếu ứng viên giải bài offline trên IDE cá nhân, họ chỉ cần Reply trực tiếp email kèm file bài giải. Hệ thống webhook tại endpoint /recruitment/api/webhook/email-reply sẽ tự động trích xuất token bảo mật, gán bài làm vào hồ sơ ứng viên và thông báo cho người chấm.

public class AssessmentSolution {
    public static double calculateScore(Map<String, Integer> scores, Map<String, Double> weights) {
        double weightedSum = 0;
        double totalWeight = 0;
        for (var entry : scores.entrySet()) {
            double w = weights.getOrDefault(entry.getKey(), 1.0);
            weightedSum += entry.getValue() * w;
            totalWeight += w;
        }
        return totalWeight > 0 ? (weightedSum / totalWeight) : 0;
    }
}

Đặc Tả Yêu Cầu Đồ Án Kì IV: Portal Tuyển Dụng & Phỏng Vấn (ATS)

Bảng đối chiếu 7 nhóm yêu cầu cốt lõi với cấu trúc Module mã nguồn (Spring MVC + Flutter).

1. Giao bài test & đánh giá năng lực (Assessments)

Ngân hàng đề thi, giao bài test bảo mật token cho ứng viên. Hỗ trợ 2 hình thức nộp: nộp trực tiếp trên Web và tự động ghi nhận bài làm khi ứng viên Reply email thông qua Inbound Webhook (/recruitment/api/webhook/email-reply).

2. Đặt lịch phỏng vấn, phân công, scorecard, tổng hợp điểm

Quản lý lịch phỏng vấn theo tuần/ngày, phân công người phỏng vấn (Interviewer), phiếu chấm điểm chuyên sâu theo thang điểm (Scorecard) và tổng hợp kết quả tự động.

3. Offer và luồng phê duyệt offer

Tạo thư mời nhận việc với mức lương, phụ cấp, ngày đi làm. Quy trình duyệt phân cấp (Draft → Pending → Approved → Sent → Accepted).

4. Onboarding cơ bản (Checklist)

Danh mục tiếp nhận nhân sự mới: Ký hợp đồng lao động, cấp email công ty, máy tính, phân công mentor và tham gia định hướng.

5. Dashboard, báo cáo & Export Excel

Biểu đồ phễu 6 giai đoạn, chỉ số Time-to-Hire, thống kê nguồn ứng viên và nút xuất toàn bộ dữ liệu ra Excel/CSV (/recruitment/export-excel).

6. Career site công khai + Nộp CV mở + Tra cứu trạng thái + Thi online

Cổng tuyển dụng public lọc theo ngành nghề & khu vực; form nộp CV mở vào Talent Pool; tra cứu trạng thái tiến trình thời gian thực theo mã APP; trang thi bảo mật có đồng hồ đếm ngược.

7. Quản trị hệ thống, RBAC, phòng ban, template email, audit log

Phân quyền vai trò (Admin, Recruiter, Interviewer), cấu hình quy trình các bước tuyển dụng, quản lý template email tự động và nhật ký audit log lưu vết mọi hoạt động.
