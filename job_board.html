Senior Java Backend Engineer

TP. Hồ Chí Minh 28 - 42 Triệu Toàn thời gian

Mô tả công việc:

  • Tham gia thiết kế, phát triển và tối ưu hóa hệ thống Backend phục vụ hơn 500,000 người dùng hàng ngày.
  • Xây dựng các microservices hiệu năng cao sử dụng Java 21, Spring Boot 3 và kiến trúc hướng sự kiện (Event-driven) với Apache Kafka.
  • Tối ưu hóa cơ sở dữ liệu PostgreSQL, lập chỉ mục và xử lý các bài toán Concurrency Control, High Availability.
  • Phối hợp cùng đội ngũ Product và Mobile (Flutter) để cung cấp các chuẩn REST API và gRPC bảo mật, tin cậy.

Yêu cầu ứng viên:

  • Từ 3+ năm kinh nghiệm làm việc chuyên sâu với Java và Spring Boot ecosystem.
  • Thành thạo cơ sở dữ liệu quan hệ (PostgreSQL / MySQL) và NoSQL (Redis, MongoDB).
  • Hiểu biết vững chắc về Design Patterns, Clean Architecture và Docker/Kubernetes cơ bản.
  • Tinh thần trách nhiệm cao, chủ động trong công việc và có tư duy giải quyết vấn đề tốt.

  • Bảo hiểm sức khỏe cao cấp (PVI Care), khám sức khỏe định kỳ hàng năm.
  • Cung cấp MacBook Pro M-series và màn hình 4K làm việc.
  • Hỗ trợ 2 ngày làm việc từ xa (Work From Home) mỗi tuần.
